# AirSky Glass Browser
![AozoraBrowser_Header](https://github.com/Aozora9200/AirSky-Glass-Browser/blob/main/app/src/main/res/drawable/aozora_default.png)


- Aozora と FireFox がベースの Web ブラウザです。
- 動作バージョン Android 8.0 ～ Android 17

## 🌟 主要な新機能・デザイン刷新

* **AirSkyセットアップ & 起動画面の刷新**: 初回起動時の演出を一新。Lottieアニメーションを用いたPixel風のモダンなセットアップ画面を実装し、背景には美しい青空のテーマを採用しました。また、静かで心地よい新しい起動音を導入しています。
* **Pixel風モダンUIの全面展開**:
* 設定画面、ポップアップメニュー、ダウンロードマネージャー、履歴、電卓、データ使用量アクティビティ、ヘルプ、アプリ情報などをPixel風の洗練されたモダンデザインに統一しました。
* 各種ツール（QRコード生成、メモ機能、EXECコンソールなど）のUIを大幅にブラッシュアップ。


* **タブレットUIの導入**:
* 初回起動時や設定から選択可能な「タブレットモード」を実装。PCライクな上部タブ配置や、ショートカット・URLバー・メニュー等を最適に統合したレイアウトを提供します（バーの位置を上／下に切り替えるカスタマイズも可能）。


* **二画面端末（AYN Thor等）への対応**:
* 上下に画面を分割し、シームレスに連携してウェブサイトを閲覧できる二画面モードに対応しました。



## 🌐 ブラウザコア・機能の強化

* **GeckoView への移行 & 拡張機能対応**:
* GeckoViewベースへの移行に伴い、Firefox用拡張機能（.xpiファイルやアドオンストアからのインストール）に対応した拡張機能マネージャーを搭載しました。


* **高度なシークレットモード**:
* Chromeと同様に、セッション専用の独立した一次的プロファイル（インメモリ領域）で動作するように変更。さらに、シークレットタブ閲覧中のスクリーンショットや画面共有ブロック、ダークテーマ固定などのセキュリティを強化しました。


* **タブグループ機能**:
* タブ同士を重ねてグループ化できるタブグループ機能を実装。タブレットUIや通常UIの双方でスムーズにグループ操作が行えます。


* **非アクティブタブの自動管理**:
* 重複しているタブや長期間（選択可能な日数）使用されていないタブを自動で「非アクティブタブ」としてまとめ、3ヶ月後に整理・削除できる機能を追加しました。


* **パスワードマネージャー & 生体認証**:
* パスワード、住所、クレジットカード情報などを厳重に暗号化して管理するパスワードマネージャーを搭載。自動入力の利用時には生体認証による本人確認を必須とし、セキュリティを大幅に高めました。


* **ガラスデザイン（Liquid Glass風）設定**:
* ガラスエフェクトのON/OFFや屈折表現をカスタマイズできる専用設定画面を追加しました。



## 🛠️ 高度なツールと実行環境

* **Java / Python プログラム実行環境**:
* Android内蔵シェルや `ProcessBuilder` を活用し、一部のJava（JAR）およびPythonプログラムをGUI（Tkinter/Flet/wxPython等）対応で実行できるツールを実験的機能として追加しました。さらに、それらのショートカットをツールやホーム画面に追加可能です。


* **改良版 EXEC コンソール**:
* 本格的なAndroidシェル（必要に応じてsu権限対応）を操作できるPixel風のコンソールを搭載しました。


* **仮想マウス・ゲームモード・コントローラー対応**:
* リモートデスクトップのようにタッチで操作できる仮想マウスモードや、ポインターロック対応サイトのサポート、ゲーム向け常時ソフトキーボード表示（ローマ字入力対応）、コントローラーのボタン割り当て機能を実装しました。



## 🔄 データ移行とバックアップ

* **端末間データ引っ越し機能**:
* AirSky Browser同士で、Bluetooth、QuickShare、またはQRコードを用いて、タブ、履歴、ブックマーク、保存したページ、設定などのデータをまるごと移行できる機能を搭載しました。


* **旧Aozoraからのデータ引き継ぎ**:
* 旧アプリ「Aozora」からのデータ移行（自動検出による `.az` ファイルのインポート）に対応し、スムーズに環境を引き継ぐことができます。



## 🐛 その他の改善・不具合修正

* Yahooニュース等での動画再生エラー（環境依存エラー）の修正。
* ダウンロード管理の改善（ファイル名の `.bin` 化問題の修正、ウイルススキャン連携、ポップアップアニメーション等）。
* 翻訳機能の仕様調整（「元の言語で表示」オプションや、通知・もとに戻す機能の追加）。
* スワイプ更新の動作安定化（誤作動の防止）。
* パスキー機能、リーディングモードの追加。
* Google Playストア等の特定URLスキームが正しくアプリ連携されるよう修正。
* その他、細かなスクロール挙動のガタつき解消、アニメーションの躍動感向上、および安定性の改善を多数実施しました。
